# 🧟 Зомбимания - Игра на выживание

Аркадная игра-кликер, где вам предстоит уничтожать зомби, появляющихся в случайных местах на карте. Игра на время - успейте набрать максимум очков, пока не истек таймер!

## 🎯 Особенности

- Динамический зомби, движущийся по экрану и отскакивающий от стен
- Управление битой, которая следует за курсором мыши
- Система очков и таймер обратного отсчета
- Красивая анимация удара и движения зомби
- Эффектный экран "Game Over" с анимацией
- Таблица результатов в конце игры

## 🎮 Управление

| Действие | Управление |
|----------|------------|
| Перемещение биты | Движение мыши |
| Удар по зомби | Зажать ЛКМ |
| Отпустить удар | Отпустить ЛКМ |

**Механика игры:**
1. Зомби хаотично движется по экрану, отскакивая от границ
2. Ваша задача - навести курсор на зомби и зажать левую кнопку мыши, чтобы ударить битой
3. За каждое попадание начисляется 1 очко
4. Зомби телепортируется в новое случайное место после попадания
5. Игра длится 20 секунд (таймер отсчитывает вниз)
6. По истечении времени показывается финальная анимация и ваш результат

### Необходимые файлы изображений:

🎲 Игровая механика (подробно)
Движение зомби
Зомби движется с постоянной скоростью по экрану

При столкновении с границей меняет направление на противоположное

Скорость случайная (1-5 пикселей за кадр)

Направление выбирается случайно (лево/право + верх/низ)

Система попаданий
Для удара необходимо зажать ЛКМ, когда курсор находится над зомби

Проверка коллизии происходит по прямоугольной области зомби (150x150 пикселей)

При попадании:

Счет увеличивается на 1

Зомби телепортируется в новую случайную позицию

Зомби меняет направление и скорость движения

Отображается анимация удара

Телепортация зомби
Новое место выбирается случайно в пределах игрового поля

Есть защита от телепортации слишком близко к курсору (если зомби появляется в радиусе 100 пикселей от мыши, он перемещается дальше)

Таймер и окончание игры
Игра длится 20 секунд (можно изменить в переменной time)

Каждую секунду таймер уменьшается на 1

По достижении 0 запускается анимация Game Over

Финальный экран показывает набранные очки в виде трех цифр (000-999)

🎨 Анимации
Зомби
Циклическая анимация из 2 кадров

Смена кадров каждые 200 мс

Удар битой
При нажатии ЛКМ бита меняет изображение на "ударную" версию

При отпускании возвращается в обычное состояние

Game Over
Анимация из 10 кадров

Каждый кадр отображается 50 мс

После анимации показывается счет игрока
